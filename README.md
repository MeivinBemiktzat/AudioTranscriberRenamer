# Audio Transcriber & Renamer (מתמלל ומשנה שמות קובצי שמע)

תוכנת Windows שולחנית מלאה לתמלול אוטומטי ושינוי שמות של קובצי שמע (כולל הקלטות מטלפונים ניידים כגון `m4a`, `aac`, `amr`, `mp3`, `ogg`, `wav`).

---

## תכונות עיקריות

- **זיהוי שפה אוטומטי**: דוגם ומנתח את האודיו מול שפות שונות (עברית, אנגלית, ערבית, רוסית ועוד) ובוחר אוטומטית את השפה המתאימה ביותר.
- **טיפול בהקלטות ארוכות**: חלוקה חכמה למקטעים (Chunks) כדי למנוע מגבלות אורך בשירות התמלול.
- **תמיכה מלאה בהקלטות טלפון**: המרה זמנית בזיכרון ללא פגיעה בקובץ המקורי.
- **תצוגה מקדימה בטוחה**: מציג השוואה (`שם מקורי ← שם חדש`) וממתין לאישור המשתמש לפני שינוי השמות בפועל.
- **מניעת דריסה**: הוספת מונה סידורי `(2)`, `(3)` במידה ונוצר שם קיים.
- **יצוא TXT**: אפשרות לשמירת קובץ טקסט עם התמלול המלא ליד קובץ השמע.
- **חסינות מתקלות**: דילוג על קבצים פגומים והמשך ריצה רציפה.
- **ממשק גרפי בעברית (RTL)**.
